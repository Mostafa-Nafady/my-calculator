## [1.1.0] - 2026-09-02

### Added

- Comprehensive documentation suite: rewritten `README.md`, `docs/architecture.md`, `docs/pages-reference.md`, and `docs/components.md`
- JSDoc annotations to all functions in `basics-10-function-refactoring/assets/scripts/app.js`, `vendor.js`, and `assets/scripts/gallery.js`
- ASx About page (`asx.html`, `asx.js`, `asx.css`) as a secondary about page

### Changed

- Rewrote `README.md` with full project structure, pages table, architecture overview, and quick start guide

## [1.0.0] - 2026-08-06

### Added

- Gallery page (`gallery.html`, `gallery.js`, `gallery.css`) with interactive card grid and modal overlay for browsing all calculators
- XPY Calculator (`xpy/`) — X raised to the power of Y (X^Y)
- UYT Calculator (`uyt/`) — (U × Y) ÷ T with divide-by-zero protection
- Shared `Header.js` component for consistent navigation across all pages
- Multiple informational calculator pages: ASD, QWE, CVXZ, NNN, SDSSA
- About page (`about.html`) with project overview
- Basic 4-function calculator (`basics-10-function-refactoring/`) with add, subtract, multiply, divide operations
- Shared global stylesheet (`assets/styles/app.css`) with dark blue (`#023d6d`) color scheme
- Google Fonts (Roboto) integration

## [0.1.0] - 2022-06-10

### Added

- Initial project creation with basic calculator structure
